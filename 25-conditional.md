# Conditionals in English

## 1. What Are Conditionals?

**Conditionals** are sentences that describe a **condition** and its **result**.

They usually contain:

- An **if-clause** → the condition
- A **main clause** → the result

### Basic Structure

> **If + condition, result.**

Example:

> **If it rains, we will stay home.**

- **If it rains** → Condition
- **we will stay home** → Result

---

# 2. Summary of the Four Main Conditionals

| Type | Main Use | If-Clause | Main Clause | Example |
|---|---|---|---|---|
| **Zero Conditional** | Facts, rules, general truths | Present simple | Present simple | If you heat ice, it melts. |
| **First Conditional** | Real/possible future | Present simple | will + verb | If it rains, we will stay home. |
| **Second Conditional** | Unreal/unlikely present or future | Past simple | would + verb | If I had more money, I would travel. |
| **Third Conditional** | Unreal past / imagined past result | Past perfect | would have + past participle | If I had studied, I would have passed. |

---

# 3. Zero Conditional

The **zero conditional** is used for:

- General truths
- Scientific facts
- Rules
- Habits
- Things that are always or generally true

### Structure

> **If + present simple, present simple**

### Examples

> If you heat ice, **it melts**.

> If it rains, **the ground gets wet**.

> If people don't eat, **they get hungry**.

| If-Clause | Result |
|---|---|
| If you heat ice | it melts |
| If it rains | the ground gets wet |
| If people don't eat | they get hungry |

### Important

The result is generally or always true.

> **If you press this button, the machine starts.**

---

# 4. First Conditional

The **first conditional** describes a **real or possible situation in the future**.

### Structure

> **If + present simple, will + base verb**

### Examples

> If it rains, **we will stay home**.

> If you study hard, **you will pass the exam**.

> If I have time, **I will call you**.

| If-Clause | Result |
|---|---|
| If it rains | we will stay home |
| If you study hard | you will pass the exam |
| If I have time | I will call you |

### Important

The if-clause normally uses the **present simple**, not *will*.

> ❌ If it **will rain**, we will stay home.

> ✅ If it **rains**, we will stay home.

---

# 5. Second Conditional

The **second conditional** describes:

- Unreal situations in the present
- Imaginary situations
- Unlikely future situations
- Dreams or hypothetical situations

### Structure

> **If + past simple, would + base verb**

### Examples

> If I had more money, **I would travel more**.

> If I were you, **I would apologize**.

> If she lived closer, **we would see her more often**.

| If-Clause | Result |
|---|---|
| If I had more money | I would travel more |
| If I were you | I would apologize |
| If she lived closer | we would see her more often |

### Important: "Were"

In formal English, **were** is commonly used with all subjects in hypothetical **if-clauses**.

> If I **were** you, I would accept the offer.

> If he **were** here, he would help us.

In informal English, **was** is sometimes used:

> If I **was** you...

But **If I were you** is the standard expression.

---

# 6. Third Conditional

The **third conditional** describes an **unreal situation in the past**.

It talks about something that **did not happen** and imagines a different past result.

### Structure

> **If + past perfect, would have + past participle**

### Examples

> If I had studied harder, **I would have passed the exam**.

> If she had left earlier, **she would have caught the bus**.

> If we had known about the problem, **we would have helped**.

| Past Condition | Imagined Past Result |
|---|---|
| If I had studied harder | I would have passed |
| If she had left earlier | she would have caught the bus |
| If we had known | we would have helped |

### Meaning

> I didn't study hard → I didn't pass.

The third conditional imagines a different past:

> If I **had studied harder**, I **would have passed**.

---

# 7. Zero vs. First Conditional

| Zero Conditional | First Conditional |
|---|---|
| General truth | Possible future situation |
| Present + present | Present + will |
| If you heat water, it boils. | If you heat the water, I will make tea. |
| Usually always true | Possible in the future |

### Compare

> If you **heat ice**, it **melts**.  
> → General scientific fact.

> If you **heat the water**, I **will make tea**.  
> → Specific future possibility.

---

# 8. First vs. Second Conditional

| First Conditional | Second Conditional |
|---|---|
| Real/possible future | Unreal/unlikely future |
| If + present | If + past |
| will + verb | would + verb |
| If I have time, I will help you. | If I had more time, I would help you. |

### Compare

> If I **have** enough money, I **will buy** a new phone.  
> → I may have enough money.

> If I **had** enough money, I **would buy** a new phone.  
> → I probably don't have enough money.

---

# 9. Second vs. Third Conditional

| Second Conditional | Third Conditional |
|---|---|
| Unreal present/future | Unreal past |
| If + past simple | If + past perfect |
| would + verb | would have + past participle |
| If I had money, I would travel. | If I had had money, I would have traveled. |

### Compare

> If I **had** more money, I **would travel**.  
> → I don't have enough money now.

> If I **had had** more money, I **would have traveled**.  
> → I didn't have enough money in the past.

---

# 10. Mixed Conditionals

**Mixed conditionals** combine different time periods.

They are used when a past condition has a present result, or a present condition has a past result.

### Past Condition → Present Result

> If I **had studied medicine**, I **would be a doctor now**.

Meaning:

- I didn't study medicine in the past.
- I am not a doctor now.

### Present Condition → Past Result

> If I **were more organized**, I **would have finished the project yesterday**.

Meaning:

- I am not very organized now.
- I didn't finish the project yesterday.

| Type | Structure | Example |
|---|---|---|
| Past → Present | If + past perfect + would + verb | If I had studied medicine, I would be a doctor now. |
| Present → Past | If + past simple + would have + past participle | If I were more organized, I would have finished it yesterday. |

---

# 11. "Unless"

**Unless** means **if not**.

### Examples

> **Unless you hurry**, you will be late.

> I won't go **unless you come with me**.

> **Unless it rains**, we will play outside.

### Compare

> If you **don't hurry**, you will be late.

> Unless you **hurry**, you will be late.

Both have a similar meaning.

| If | Unless |
|---|---|
| If you don't study, you will fail. | Unless you study, you will fail. |
| If it doesn't rain, we will go. | Unless it rains, we will go. |

---

# 12. "As Long As"

**As long as** means **provided that / on the condition that**.

### Examples

> You can borrow my car **as long as you drive carefully**.

> You can stay here **as long as you are quiet**.

> I'll help you **as long as you listen to me**.

| Condition | Result |
|---|---|
| as long as you drive carefully | You can borrow my car |
| as long as you are quiet | You can stay here |
| as long as you listen | I'll help you |

---

# 13. "Provided That"

**Provided that** means **if / on the condition that**.

### Examples

> You can go **provided that you finish your homework**.

> We will go **provided that the weather is good**.

> You can use the room **provided that you keep it clean**.

It is more formal than **if**.

---

# 14. "Even If"

**Even if** means that the result will happen **regardless of the condition**.

### Examples

> I will go **even if it rains**.

> She will help you **even if you don't ask**.

> I'll finish the work **even if it takes all night**.

### Compare

> **If** it rains, I won't go.  
> → Rain changes the result.

> **Even if** it rains, I will go.  
> → Rain does not change the result.

---

# 15. "Only If"

**Only if** means that something happens **only when a particular condition is met**.

### Examples

> You can leave **only if you finish your work**.

> I will help you **only if you tell me the truth**.

> We can go **only if everyone agrees**.

---

# 16. "In Case"

**In case** is used when something is done as a precaution because something might happen.

### Examples

> Take an umbrella **in case it rains**.

> Bring some money **in case you need it**.

> Save my number **in case you need help**.

### Important

**In case** does not have exactly the same meaning as **if**.

> Take an umbrella **in case it rains**.  
> → Take it as a precaution.

> Take an umbrella **if it rains**.  
> → Take it only if it actually rains.

---

# 17. If-Clause at the Beginning or End

The if-clause can come before or after the main clause.

### If-Clause First

> **If it rains,** we will stay home.

A comma is normally used.

### Main Clause First

> We will stay home **if it rains**.

A comma is normally not needed.

| Position | Example |
|---|---|
| If-clause first | **If you study,** you will pass. |
| If-clause second | You will pass **if you study**. |

---

# 18. Other Words Instead of "If"

| Expression | Meaning | Example |
|---|---|---|
| **unless** | if not | **Unless** you hurry, you'll be late. |
| **as long as** | provided that | You can stay **as long as** you're quiet. |
| **provided that** | if | You can go **provided that** you finish. |
| **on condition that** | if | I'll agree **on condition that** you help. |
| **even if** | regardless of whether | I'll go **even if** it rains. |
| **only if** | if and only if the condition is met | You can enter **only if** you have a ticket. |
| **in case** | as a precaution | Take an umbrella **in case** it rains. |

---

# 19. Conditional Tenses at a Glance

| Conditional | If-Clause | Result Clause | Example |
|---|---|---|---|
| **Zero** | Present simple | Present simple | If you heat ice, it melts. |
| **First** | Present simple | will + verb | If I have time, I will help. |
| **Second** | Past simple | would + verb | If I had time, I would help. |
| **Third** | Past perfect | would have + past participle | If I had had time, I would have helped. |
| **Mixed** | Different combinations | Different combinations | If I had studied, I would have a better job now. |

---

# 20. Common Mistakes

| Incorrect | Correct | Reason |
|---|---|---|
| If it **will rain**, we will stay home. | If it **rains**, we will stay home. | Use present simple in the first conditional if-clause. |
| If I **would have** money, I would travel. | If I **had** money, I would travel. | Use past simple in the second conditional. |
| If I **would have studied**, I would have passed. | If I **had studied**, I would have passed. | Use past perfect in the third conditional if-clause. |
| If I were you, I **will** apologize. | If I were you, I **would** apologize. | Second conditional uses **would**. |
| Unless you **don't hurry**, you'll be late. | Unless you **hurry**, you'll be late. | **Unless** already means "if not." |

---

# 21. How to Identify a Conditional Sentence

Ask these questions:

| Question | Example |
|---|---|
| Is there a condition? | **If you study** |
| Is there a result? | **you will pass** |
| Is the condition introduced by if or another conditional expression? | if, unless, provided that |
| What time does it refer to? | Present, future, or past |
| Is the situation real or unreal? | Real possibility or imaginary situation |

### Example

> **If I had more money, I would travel more.**

1. **If I had more money** → Condition
2. **I would travel more** → Result
3. **had** → Past simple
4. **would travel** → Would + base verb
5. The situation is hypothetical.
6. Therefore, it is a **second conditional**.

---

# 22. Conditionals in One Table

| Type | Meaning | Structure | Example |
|---|---|---|---|
| **Zero** | General truth | If + present, present | If you don't eat, you get hungry. |
| **First** | Real future possibility | If + present, will + verb | If I finish early, I will call you. |
| **Second** | Unreal/unlikely present or future | If + past, would + verb | If I were rich, I would travel. |
| **Third** | Unreal past | If + past perfect, would have + past participle | If I had studied, I would have passed. |
| **Mixed** | Different time relationships | Mixed forms | If I had studied, I would have a better job now. |

---

# 23. Easy Way to Remember

| Conditional | Think of It As |
|---|---|
| **Zero** | Always / generally true |
| **First** | Possible future |
| **Second** | Imaginary or unlikely |
| **Third** | Imaginary past |
| **Mixed** | Different time periods |

## Key Point

Conditionals connect a **condition** with a **result**.

### Main Patterns

> **Zero:** If + present → present  
> If you heat ice, **it melts**.

> **First:** If + present → will + verb  
> If it rains, **we will stay home**.

> **Second:** If + past → would + verb  
> If I had money, **I would travel**.

> **Third:** If + past perfect → would have + past participle  
> If I had studied, **I would have passed**.

> **Mixed:** Different time periods  
> If I had studied harder, **I would have a better job now**.
