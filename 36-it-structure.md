# It Structure in English

## 1. What Is "It"?

**It** is a pronoun that can refer to a thing, animal, situation, idea, or weather/time condition.

It is also used as a **dummy subject** when the real subject comes later or is not a specific noun.

---

# 2. Main Uses of "It"

| Use | Function | Example |
|---|---|---|
| **Personal pronoun** | Refers to a thing, animal, or situation | I bought a phone. **It** is expensive. |
| **Weather** | Talks about weather | **It is raining.** |
| **Time** | Tells the time | **It is five o'clock.** |
| **Date** | Talks about dates | **It is Monday.** |
| **Distance** | Talks about distance | **It is 5 km** from here. |
| **Dummy subject** | Introduces a real subject later | **It is important to study.** |
| **Emphasis** | Emphasizes part of a sentence | **It was John who called me.** |
| **Situation** | Refers to a general situation | **It is difficult to explain.** |

---

# 3. It as a Personal Pronoun

Use **it** to replace a singular thing, animal, or previously mentioned idea.

### Structure

> **Noun + sentence. It + verb...**

| Example | What "it" Refers To |
|---|---|
| I bought a car. **It** is new. | car |
| Where is my phone? **It** is on the table. | phone |
| I found a dog. **It** was very friendly. | dog |
| He made a mistake. **It** was serious. | mistake |

### Example

> I have a new laptop. **It** works very well.

---

# 4. It for Animals

**It** can refer to an animal when its sex is unknown or unimportant.

| Example |
|---|
| Look at that dog. **It** is very cute. |
| I saw a bird. **It** was sitting in a tree. |
| The cat is sleeping. **It** looks comfortable. |

When the animal's sex is known and important, **he** or **she** can be used.

> My dog is called Max. **He** is very friendly.

---

# 5. It for Weather

Use **it** as the subject when talking about weather.

### Structure

> **It + be + adjective**

> **It + verb**

| Weather | Example |
|---|---|
| Rain | **It is raining.** |
| Snow | **It is snowing.** |
| Temperature | **It is hot.** |
| Cold | **It is cold.** |
| Wind | **It is windy.** |
| Sunshine | **It is sunny.** |
| Cloud | **It is cloudy.** |

### Examples

> **It is raining** heavily.

> **It is very cold** today.

> **It was sunny** yesterday.

---

# 6. It for Time

Use **it** to tell the time.

### Structure

> **It + be + time**

| Example |
|---|
| **It is five o'clock.** |
| **It is half past three.** |
| **It is quarter to ten.** |
| **It was midnight.** |
| **It is nearly noon.** |

### Question

> **What time is it?**

Answer:

> **It is seven o'clock.**

---

# 7. It for Days and Dates

Use **it** to talk about the day or date.

| Example |
|---|
| **It is Monday.** |
| **It is Friday today.** |
| **It is June 10th.** |
| **It was my birthday yesterday.** |
| **It will be Christmas tomorrow.** |

---

# 8. It for Distance

Use **it** to describe distance.

### Structure

> **It + be + distance + from/to...**

| Example |
|---|
| **It is five kilometers** from here. |
| **It is a long way** to the airport. |
| **It is about 20 minutes** from my house. |
| **It is three miles** to the city center. |

---

# 9. It for General Situations

"It" can refer to a situation or circumstance.

| Example |
|---|
| **It is difficult** to find a job. |
| **It was surprising** to see him there. |
| **It is nice** to meet you. |
| **It is impossible** to finish today. |
| **It is dangerous** to drive too fast. |

Here, **it** does not refer to a particular object.

---

# 10. It + Be + Adjective + Infinitive

Use **it** to introduce an infinitive phrase.

### Structure

> **It + be + adjective + to + verb**

| Example |
|---|
| **It is important to study.** |
| **It is difficult to learn English.** |
| **It is easy to make mistakes.** |
| **It is good to exercise regularly.** |
| **It is dangerous to drive fast.** |

### Compare

> **To learn English is important.**

More natural:

> **It is important to learn English.**

---

# 11. It + Be + Adjective + That-Clause

Use **it** to introduce a clause beginning with **that**.

### Structure

> **It + be + adjective + that + clause**

| Example |
|---|
| **It is important that you study.** |
| **It is possible that he is right.** |
| **It is clear that she understands.** |
| **It is surprising that they won.** |
| **It is likely that it will rain.** |

---

# 12. It + Be + Noun + To-Infinitive

Use **it** when the real subject is an infinitive phrase.

### Structure

> **It + be + noun + to + verb**

| Example |
|---|---|
| **It is a good idea to study every day.** |
| **It is a mistake to ignore the problem.** |
| **It is a pleasure to meet you.** |
| **It is a good thing to help others.** |

---

# 13. It + Be + Noun + That-Clause

### Structure

> **It + be + noun + that + clause**

| Example |
|---|
| **It is a fact that English is widely spoken.** |
| **It is a pity that he cannot come.** |
| **It is a shame that we missed the train.** |
| **It is a good thing that nobody was hurt.** |

---

# 14. It as a Formal / Dummy Subject

Sometimes **it** is used as a grammatical subject even though it has no specific meaning.

### Structure

> **It + be + adjective + real subject**

| Example |
|---|
| **It is important to exercise.** |
| **It is difficult to understand this.** |
| **It is necessary to arrive early.** |
| **It is impossible to know the future.** |

The real meaning comes from:

> **to exercise**

> **to understand this**

> **to arrive early**

> **to know the future**

---

# 15. It Takes a Long Subject

English often puts a long subject at the end of the sentence and uses **it** at the beginning.

### Structure

> **It + verb/adjective + ... + real subject**

| Less Natural | More Natural |
|---|---|
| To learn a new language is difficult. | **It is difficult to learn a new language.** |
| That he passed the exam was surprising. | **It was surprising that he passed the exam.** |
| To work all day is tiring. | **It is tiring to work all day.** |

---

# 16. It + Take

Use **it takes** to talk about the amount of time needed to do something.

### Structure

> **It + take + person + time + to + verb**

| Example |
|---|
| **It takes me 30 minutes to get to work.** |
| **It takes two hours to cook this meal.** |
| **It took her three days to finish the project.** |
| **It will take us an hour to get there.** |

### Tense Forms

| Tense | Structure | Example |
|---|---|---|
| Present | It takes | **It takes** an hour. |
| Past | It took | **It took** an hour. |
| Future | It will take | **It will take** an hour. |
| Present perfect | It has taken | **It has taken** an hour. |

---

# 17. It Seems / Appears

Use **it seems** or **it appears** to express an impression or conclusion.

### Structure

> **It seems/appears + adjective**

> **It seems/appears + that-clause**

| Example |
|---|
| **It seems difficult.** |
| **It seems that he is tired.** |
| **It appears that she is right.** |
| **It seems unlikely that they will come.** |

---

# 18. It Looks / Sounds / Feels

"It" can refer to a situation or thing.

| Verb | Example |
|---|---|
| **look** | **It looks good.** |
| **sound** | **It sounds interesting.** |
| **feel** | **It feels strange.** |
| **smell** | **It smells delicious.** |
| **taste** | **It tastes great.** |

---

# 19. It + Be + Preposition

"It" can refer to a situation, location, or condition.

| Example |
|---|
| **It is in the box.** |
| **It is on the table.** |
| **It is under the chair.** |
| **It is near the station.** |
| **It is from my old school.** |

---

# 20. It in Passive Structures

"It" can be used as a formal subject in passive constructions.

### Structure

> **It + be + past participle + that-clause**

| Example |
|---|
| **It is believed that he is innocent.** |
| **It is said that she is very rich.** |
| **It is expected that prices will rise.** |
| **It is known that English is widely spoken.** |
| **It is thought that he left early.** |

### Common Expressions

| Expression | Example |
|---|---|
| It is believed that... | **It is believed that he is honest.** |
| It is said that... | **It is said that she is a great teacher.** |
| It is known that... | **It is known that water freezes at 0°C.** |
| It is expected that... | **It is expected that sales will increase.** |

---

# 21. It-Cleft Sentences

Use **It + be** to emphasize a particular part of a sentence.

### Structure

> **It + be + emphasized element + who/that + clause**

| Normal Sentence | Emphasized Sentence |
|---|---|
| John called me. | **It was John who called me.** |
| Mary bought the car. | **It was Mary who bought the car.** |
| I met him yesterday. | **It was yesterday that I met him.** |
| She wanted the red one. | **It was the red one that she wanted.** |

### Purpose

The structure emphasizes **who, what, when, where, or why**.

---

# 22. It + Be + Time

"It" can be used in expressions about time.

| Structure | Example |
|---|---|
| It is time to + verb | **It is time to go.** |
| It is time for + noun | **It is time for lunch.** |
| It is time for + person + to + verb | **It is time for us to leave.** |
| It is time + subject + past tense | **It is time we went home.** |

---

# 23. It Is Time

### Structure 1

> **It is time to + verb**

> **It is time to go home.**

### Structure 2

> **It is time for + noun/pronoun + to + verb**

> **It is time for us to leave.**

### Structure 3

> **It is time + subject + past tense**

> **It is time we went home.**

The third structure often means that something should happen **now or soon**.

---

# 24. It + Be + Worth

Use **it is worth** to say that something is valuable or beneficial.

### Structure

> **It is worth + -ing**

| Example |
|---|
| **It is worth trying.** |
| **It is worth learning English.** |
| **It is worth visiting the museum.** |
| **It isn't worth worrying about.** |

Common mistake:

> ❌ It is worth **to try**.

> ✅ It is worth **trying**.

---

# 25. It + Be + No Use / No Good

Use these expressions to say that an action is useless.

### Structure

> **It is no use + -ing**

> **It is no good + -ing**

| Example |
|---|
| **It is no use arguing.** |
| **It is no good complaining.** |
| **It is no use worrying about it.** |
| **It is no good waiting here.** |

---

# 26. It + Be + Adjective + For/Of

Two important structures are:

### It is + adjective + for + person + to-infinitive

> **It is difficult for me to understand.**

### It is + adjective + of + person + to-infinitive

> **It was kind of you to help me.**

| Structure | Use | Example |
|---|---|---|
| **It is + adjective + for + person + to...** | Describes the action/situation | **It is difficult for him to swim.** |
| **It is + adjective + of + person + to...** | Describes the person's character/behavior | **It was kind of her to help.** |

---

# 27. It + Be + Adjective: For vs. Of

| For | Of |
|---|---|
| Describes the situation/action | Describes the person |
| It is difficult **for him** to do it. | It is kind **of him** to help. |
| It is important **for students** to study. | It was careless **of him** to forget. |
| It is dangerous **for children** to swim here. | It was foolish **of me** to do that. |

---

# 28. Negative Forms with It

Use **not** after the verb **be** or auxiliary verb.

| Positive | Negative |
|---|---|
| It is easy. | **It isn't easy.** |
| It is raining. | **It isn't raining.** |
| It was difficult. | **It wasn't difficult.** |
| It will be possible. | **It won't be possible.** |
| It has been successful. | **It hasn't been successful.** |

---

# 29. Questions with It

The question structure depends on the meaning.

| Statement | Question |
|---|---|
| It is cold. | **Is it cold?** |
| It is raining. | **Is it raining?** |
| It is difficult. | **Is it difficult?** |
| It was expensive. | **Was it expensive?** |
| It will be possible. | **Will it be possible?** |

### Time

> **What time is it?**

### Weather

> **Is it raining?**

---

# 30. It vs. There

**It** and **there** have different functions.

| It | There |
|---|---|
| Refers to a thing/situation or acts as a dummy subject | Introduces existence/presence |
| **It is a problem.** | **There is a problem.** |
| **It is on the table.** | **There is a book on the table.** |
| **It is difficult.** | **There is a problem.** |
| **It is raining.** | **There are many people outside.** |

### Compare

> **There is a book on the table.**  
> → A book exists/is located there.

> **It is on the table.**  
> → "It" refers to a previously mentioned book.

---

# 31. Common Mistakes

| Incorrect | Correct | Reason |
|---|---|---|
| ❌ Is raining. | ✅ **It is raining.** | Weather needs dummy **it**. |
| ❌ Is five o'clock. | ✅ **It is five o'clock.** | Time uses **it**. |
| ❌ It is a problem on the table. | ✅ **There is a problem on the table.** | Use **there** to introduce existence. |
| ❌ It is three books on the table. | ✅ **There are three books on the table.** | Existence uses **there + be**. |
| ❌ It is important study English. | ✅ **It is important to study English.** | Use infinitive after adjective. |
| ❌ It takes me one hour go home. | ✅ **It takes me one hour to go home.** | Use **to + verb**. |
| ❌ It is worth to try. | ✅ **It is worth trying.** | Use gerund after **worth**. |
| ❌ It is kind for you to help. | ✅ **It is kind of you to help.** | **Of** describes the person's behavior. |

---

# 32. Quick Structure Summary

| Structure | Use | Example |
|---|---|---|
| **It + be + adjective** | Describe a situation | **It is difficult.** |
| **It + be + noun** | Identify/evaluate | **It is a good idea.** |
| **It + be + adjective + to-infinitive** | Evaluate an action | **It is important to study.** |
| **It + be + adjective + that-clause** | Comment on a fact | **It is clear that he is right.** |
| **It + take + time + to-infinitive** | Express duration | **It takes two hours to finish.** |
| **It + seem/appear + that-clause** | Express impression | **It seems that he is tired.** |
| **It + be + past participle + that-clause** | Passive reporting | **It is believed that he left.** |
| **It + be + emphasized element + who/that** | Emphasis | **It was John who called.** |
| **It is time + to-infinitive** | Say something should happen | **It is time to leave.** |
| **It is worth + -ing** | Say something is worthwhile | **It is worth trying.** |
| **It is no use + -ing** | Say something is useless | **It is no use arguing.** |
| **It + be + weather adjective** | Talk about weather | **It is cold.** |
| **It + be + time** | Tell time | **It is six o'clock.** |
| **It + be + distance** | Express distance | **It is 5 km from here.** |

# 33. Easy Way to Remember

| Use of "It" | Think of It As | Example |
|---|---|---|
| **Thing/animal** | A replacement noun | **It** is my phone. |
| **Weather** | Weather subject | **It** is raining. |
| **Time** | Time subject | **It** is 8:00. |
| **Date/day** | Date/day subject | **It** is Monday. |
| **Distance** | Distance subject | **It** is 10 km away. |
| **Dummy subject** | Introduces a long subject | **It** is important to study. |
| **Take** | Time required | **It takes** an hour. |
| **Seem/appear** | Impression | **It seems** difficult. |
| **Cleft** | Emphasis | **It was John** who called. |
| **Passive reporting** | Formal reporting | **It is believed** that he left. |

## Key Point

The most important patterns are:

> **It is + adjective + to + verb**  
> *It is important **to study**.*

> **It is + adjective + that + clause**  
> *It is clear **that he is right**.*

> **It takes + person + time + to + verb**  
> *It takes me an hour **to get home**.*

> **It + be + weather/time/distance**  
> *It is **raining**.*  
> *It is **seven o'clock**.*  
> *It is **five kilometers** from here.*

> **It was + emphasized element + who/that...**  
> *It was **John who called me**.*

> **It is worth + -ing**  
> *It is worth **trying**.*

> **It is no use + -ing**  
> *It is no use **arguing**.*
